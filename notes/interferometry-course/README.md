# Интерферометрия: от световой волны до карты поверхности

Курс на русском языке для разработчика DigitQt, который знаком с вузовской
математикой и хочет разобраться в физических предпосылках, выводах формул и
численных алгоритмах. Комплексные числа, производные, интегралы, матрицы и МНК
разбираются в контексте измерения. Тетради содержат теорию, исполняемые эксперименты,
контрольные вопросы и ответы под раскрывающимися блоками.

используются синтетические данные с известной фазой: это позволяет отделить
правдоподобную картинку от правильного результата.

## Как открыть и выполнить

Откройте `00_math_and_conventions.ipynb` в VS Code с расширениями Python и Jupyter.
Выберите Python-ядро, в котором установлены зависимости. Для отдельного окружения
из корня репозитория в PowerShell:

```powershell
python -m venv .venv-course
.\.venv-course\Scripts\python.exe -m pip install -r notes/interferometry-course/requirements.txt
.\.venv-course\Scripts\python.exe -m jupyter lab notes/interferometry-course
```

В VS Code вместо запуска JupyterLab можно выбрать `.venv-course` в **Select Kernel**.
Каждая тетрадь самостоятельна: выполните **Restart Kernel → Run All** сверху вниз.
Рабочая папка должна быть корнем репозитория либо папкой курса. Графики и результаты
сохранены внутри тетрадей, поэтому их можно читать и без выполнения.

## Соглашения и границы моделей

- `φ` измеряется в радианах, `N=φ/(2π)` — в периодах, `W=λN` — разность оптических
  путей. Для отражения `h=W/(2 cos θ)`; знак требует соглашения о ходе лучей.
- В учебных рисунках X направлена вправо, Y вверх (`origin='lower'`). В изображениях
  Qt Y обычно направлена вниз: перенос формул требует явного преобразования.
- Пистон можно исключать при сравнении только явно. Наклон не удаляется автоматически.
  Покрытие маски и ошибка на общей области — разные характеристики.
- Python-функции в [course_lib.py](course_lib.py) служат для изучения. Трассировка
  упрощена; интерполяция по идеальным контурам в лабораторной не оценивает ошибки
  детектора полос. Чередование PSI и переменная проекция не являются точной копией
  C++-реализации или алгоритма Liu.
- Для Фурье используется корректная пара `fftshift`/`ifftshift`, включая нечётные
  размеры. Направление CWT задаётся явно. Эти учебные реализации не воспроизводят
  выявленные ограничения производственного кода.
- При несвязной апертуре относительные целые порядки не восстанавливаются из
  обёрнутой фазы автоматически. Один кадр `cos φ` сам по себе не задаёт знак фазы.
- Идеальная модель PSI предполагает стабильные фон и модуляцию между кадрами.
  Спекл, движение детали, насыщение и дрейф могут нарушить модель. Численная
  сходимость и малый остаток сами по себе не доказывают верность измерения.

## Воспроизводимая проверка

```powershell
python -X utf8 notes/interferometry-course/validate_course.py
```

Скрипт запускает отдельное IPython-ядро для каждой тетради, выполняет код, проверяет
встроенные утверждения и сохраняет выводы и графики. Для отдельных занятий:
`python -X utf8 notes/interferometry-course/validate_course.py --only 05 09`.
Отчёт: `build/course-validation/report.json`. Для проверки нужен `jupyter_client`
(устанавливается с JupyterLab); менять C++-сборку не требуется.

Такая проверка подтверждает выполнение учебных примеров. Она не заменяет проверку
производственного приложения, метрологическую калибровку или работу с реальным стендом.
