# Словарь и карта формул

| Обозначение | Смысл | Единицы |
|---|---|---|
| `E` | Электрическое поле или его комплексная амплитуда | В модели часто условные |
| `I` | Усреднённая интенсивность, отклик камеры после согласования масштаба | Условные, электроны или отсчёты |
| `a`, `b` | Фон и амплитуда модуляции в `I=a+b cos φ` | Как у `I` |
| `V=b/a` | Видность для идеальной синусоиды без насыщения | Безразмерная |
| `λ` | Длина волны в принятой среде/системе оптических путей | м, мкм или нм; согласовать с `W` |
| `φ` | Разность фаз, а не фаза колебания одного оптического поля | рад |
| `wrap(φ)` | Главный аргумент `exp(iφ)` | рад, диапазон около `[-π,π]` |
| `N=φ/(2π)` | Оптический порядок | Периоды |
| `W=λφ/(2π)` | OPD, разность оптических путей | Длина |
| `h=W/(2 cos θ)` | Высота отражающей поверхности при заданной геометрии | Длина |
| `δₙ` | Фазовый сдвиг между кадрами PSI | рад |
| `∇φ/(2π)` | Локальная пространственная частота | Периоды на единицу координаты |
| `κ(A)` | Число обусловленности матрицы задачи | Безразмерное |
| `RMS` | Среднеквадратичное значение на явно заданной маске | Как у карты |
| `PV` | Максимум минус минимум на маске | Как у карты |
| `PSD` | Спектральная плотность мощности | Например, нм²·мм для профиля с частотой в мм⁻¹ |

## Основные переходы

1. Сложить **поля**, затем усреднить квадрат: `I=I₁+I₂+2√(I₁I₂) cos φ`
   для полностью когерентных волн одинаковой поляризации.
2. Получить информацию о фазе: из геометрии полос, выделения комплексной боковой
   полосы спектра, локального комплексного вейвлета или серии PSI.
3. Развернуть фазу с учётом маски и ограничений на соседние приращения.
4. Применить согласованные геометрическую и фазовую калибровки.
5. Перейти к OPD и, при известной схеме, к высоте.
6. Подогнать нужные моды и определить, какие из них физически допустимо исключать.
7. Посчитать метрики с указанными единицами, маской и перечнем удалённых мод.

**Пистон** — постоянная добавка к карте. **Наклон** — линейная функция координат.
**Дефокус** — квадратичная радиально-симметричная мода в выбранном базисе.
**Обёртка** теряет целое число периодов; **развёртка** выбирает его при дополнительных
предположениях. **Несущая** создаёт пространственные полосы и разносит спектральные
компоненты. **Регуляризация** добавляет предположение о решении; она не создаёт
новых измеренных данных.

Средний остаток и RMS совпадают со стандартным отклонением только при подходящем
определении среднего. Малый RMS после удаления мод не означает малую полную ошибку
поверхности. Коэффициент полинома имеет смысл только вместе с формулой полинома,
нормировкой, апертурой и единицами карты.
